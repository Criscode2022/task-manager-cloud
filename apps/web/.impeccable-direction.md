## Direction contract

THESIS: Task Cloud is one column you write into, then read. The capture line is the first control, status is a visible three-way switch, and finished tasks step below open ones. This refuses the card stack, the cycling filter, and the centered create dialog.

OWN-WORLD: Daylight stone (#F3F5F4) and deep teal (#0B5E5A) for action. Night is #101614 with #8ED9D2. Literata sets the words you read; Figtree sets controls. Priority stays red, amber, and green as words, separate from the teal.

STORY: You type a task without opening a dialog, see what is still open, and narrow by priority or tag only when you ask. Settings are labeled rows, not icon buttons.

FIRST VIEWPORT: The name and search sit in the header. A sticky dock holds All / Pending / Done, then a single title field with Add. The list starts immediately under that. Details fold open under the title line. Signature interaction: that fold, one height reveal, reduced motion cuts it.

FORM: Pocket column, chosen directly because the project rule replaces the direction hand. Seed key: direct-choice.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
